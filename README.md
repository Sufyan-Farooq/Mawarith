## ۞ The Sacred Science of Inheritance (علم الفرائض)

The Prophet Muhammad ﷺ emphasized the paramount status of inheritance jurisprudence:

> **«تَعَلَّمُوا الْفَرَائِضَ وَعَلِّمُوهَا النَّاسَ، فَإِنَّهُ نِصْفُ الْعِلْمِ، وَهُوَ يُنْسَى، وَهُوَ أَوَّلُ شَيْءٍ يُنْتَزَعُ مِنْ أُمَّتِي»**  
> *"Learn the shares of inheritance and teach them to people, for it is half of knowledge and it will be forgotten, and it is the first thing that will be taken away from my Ummah."*  
> — **Sunan Ibn Majah (2719), Al-Hakim in Al-Mustadrak**

In our interconnected modern world—with multiple bank accounts, complex real estate, business equity, and dispersed families—estate distribution has become increasingly delicate. Without clear knowledge and transparent calculations, estate division often causes prolonged familial fractures and unjust deprivation of vulnerable heirs.

**Mawarith** bridges timeless classical scholarship with contemporary software engineering to guarantee mathematical exactness, total transparency, and spiritual reassurance.

## ✨ Key Capabilities

### 1. Estate Liquidation Waterfall (تصفية الحقوق المتعلقة بالتركة)
Under Shariah, inheritance division occurs strictly after settling prior rights in accordance with the classical waterfall:
1. **Burial & Funeral Costs (مؤن التجهيز والتكفين)**: Dignified, reasonable costs without extravagance.
2. **Debts with Collateral & Unsecured Debts (الديون العينية والمرسلة)**: Settling all obligations to creditors (*"قضى النبي ﷺ بالدين قبل الوصية"*).
3. **Bequests (الوصية الشرعية)**: Valid bequests to non-heirs, strictly capped at **one-third (1/3)** of the post-debt estate (*"الثلث والثلث كثير"*).
4. **Net Distributable Estate (صافي التركة للإرث)**: Exact base divided among entitled legal heirs.

### 2. Comprehensive Heir Matrix (22+ Categories)
Covers all primary and collateral relatives recognized in classical jurisprudence:
- **Spouses (الزوجية)**: Husband (1/2 or 1/4) / Wives (1/4 or 1/8 shared equally, up to 4).
- **Descendants (الفروع)**: Sons, Daughters, Grandsons (from son), Granddaughters (from son).
- **Ascendants (الأصول)**: Father, Mother, Paternal Grandfather, Maternal Grandmother, Paternal Grandmother.
- **Siblings (الحواشي)**: Full Brothers & Sisters, Paternal Brothers & Sisters, Maternal (Uterine) Brothers & Sisters (*Kalalah*).
- **Agnatic Collaterals (العصبات بالنفس)**: Nephews, Paternal Uncles, and Male First Cousins.

### 3. Consensus Fiqh Engine & Specialized Cases
- **Ashab al-Furood (أصحاب الفروض)**: Precise Quranic fractions ($1/2$, $1/4$, $1/8$, $2/3$, $1/3$, $1/6$).
- **Al-Asabat (العصبات)**: Residuary distribution by self (*bi-nafsihi*), by another (*bi-ghayrihi*), or with another (*ma'a ghayrihi*).
- **Hajb Matrix (حجب الحرمان والنقصان)**: Complete hierarchical exclusion rules (e.g., sons block grandsons and collaterals; father blocks grandfather and siblings).
- **Al-Gharrawan / Umariyyatan (المسألة العمرية)**: The historic ruling of Umar ibn al-Khattab (RA) where the mother receives $1/3$ of the remainder after the spouse share so the father receives double her share.
- **Al-'Awl (العول — Proportional Expansion)**: Handled when fractional entitlements exceed 1 (bases 6, 12, 24 expanding to 7, 8, 9, 10, 13, 15, 17, 27).
- **Al-Radd (الرد — Proportional Return)**: Proportional redistribution of surplus among blood heirs when no *Asabah* exist (excluding spouses, following the prevailing Saudi Senior Scholars / Ibn Baz & Ibn Uthaymeen fatwas).

### 4. Evidentiary Scriptural Proof (Daleel — الدليل الشرعي)
Every heir's calculated fraction includes an interactive proof modal presenting:
- Direct Quranic ayat in Arabic with English/Urdu translations (Surah An-Nisa 4:11, 4:12, 4:176).
- Sahih Hadith citations (Bukhari, Muslim, Abu Dawud, Tirmidhi, Ibn Majah).
- Classical scholarly commentary (*Tashil al-Fara'id* by Ibn 'Uthaymeen, *Al-Tahqiqat al-Mardiyyah* by Al-Fawzan).

### 5. Official Distribution Certificate (صك توزيع التركة)
Generates an official, printable Islamic Estate Decree containing:
- Complete financial audit (gross assets, debts, wasiyyah, net estate).
- Itemized asset and bank account breakdown.
- Complete table of heirs, shares, percentages, and monetary allocations.
- Formal Shariah compliance statement and timestamp.

### 6. Trilingual Bidirectional Interface (LTR / RTL)
Full first-class support for:
- **English** (Plus Jakarta Sans)
- **العربية** (Amiri Typography, True RTL layout)
- **اردو** (Noto Nastaliq Urdu Typography, True RTL layout)

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) v18+ (Node.js 20 or 22 recommended)
- `npm` or `pnpm`

### 1. Installation
```bash
git clone https://github.com/Sufyan-Farooq/Mawarith.git
cd Mawarith
npm install
```

### 2. Environment Configuration (Optional)
For the conversational AI advisor, copy `.env.example` to `.env` and add your Google Gemini API key:
```bash
cp .env.example .env
# Edit .env and set VITE_GEMINI_API_KEY=your_key_here
```
*(Note: If no API key is provided, Mawarith automatically utilizes its built-in offline Shariah rule-based advisor).*

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Run Test Suite
Mawarith includes a rigorous test suite covering 11 classical Islamic inheritance benchmark scenarios:
```bash
npm test
```

### 5. Build for Production
```bash
npm run build
```

## 📜 Verified Fiqh Test Suite

The calculation engine is validated against classic jurisprudential benchmarks:
1. **Standard Family**: Deceased male, Wife ($1/8$), Son & Daughter ($2:1$ Asabah).
2. **Al-Gharrawan with Husband**: Husband ($1/2$), Mother ($1/3$ of remainder), Father (Residue).
3. **Al-Gharrawan with Wife**: Wife ($1/4$), Mother ($1/3$ of remainder), Father (Residue).
4. **Al-'Awl (العول)**: Husband ($1/2$) + 2 Full Sisters ($2/3$) $\rightarrow$ Base 6 expands to 7.
5. **Al-Minbariyyah (المنبرية)**: Wife + 2 Daughters + Father + Mother $\rightarrow$ Base 24 expands to 27.
6. **Al-Radd (الرد)**: Mother ($1/6$) + Daughter ($1/2$) $\rightarrow$ Normalized surplus returned to 4.
7. **Hajb Blocking Matrix**: Son fully blocks grandsons, full brothers, and uncles.
8. **Hadith Case (Sahih al-Bukhari 6736)**: Daughter ($1/2$), Granddaughter ($1/6$ completing $2/3$), Full Sister (Asabah ma'a ghayriha).
9. **Kalaalah Uterine Siblings**: Mother ($1/6$), 2 Maternal Siblings sharing $1/3$ equally.
10. **Wasiyyah 1/3 Capping**: Enforcing the strict $1/3$ maximum on bequests.
11. **Estate Liquidation Waterfall**: Accurate settlement of debts and obligations before division.
